Authentication & Base URL

All OTP88 API requests require HTTPS and must include your API Key in the Authorization header formatted as a Bearer token:

                POST
                
/v1/otp/send

              

              

                Generates a cryptographically random verification code and delivers it using your chosen multi-channel strategy.
              


              

                
Request Body Parameters

                

                  

                    
                      

                        Field
                        Type
                        Required
                        Description
                      

                    
                    
                      

                        to
                        String
                        Yes
                        Recipient phone in E.164 format (e.g. +60123456789)
                      

                      

                        channel_strategy
                        String
                        No
                        waterfall (default), whatsapp, telegram, sms
                      

                      

                        sender_name
                        String
                        No
                        Sender ID or Brand header (e.g. Alibaba)
                      

                      

                        otp
                        String
                        No
                        Passcode to dispatch (auto-generated if omitted)
                      

                    
                  

                

              


              
              

                

                  

                    
                    
                    
                    
                    
                  

                  

                    

                      
                      
                      
                      
                    

                    
                  

                

                

                  

                

              

            


            
            

              

                POST
                
/v1/otp/verify

              

              

                Validates the user-supplied verification code against the stored transaction record.
              


              

                
Request Body Parameters

                

                  

                    
                      

                        Field
                        Type
                        Required
                        Description
                      

                    
                    
                      

                        transaction_id
                        String
                        Yes
                        Transaction ID returned from /v1/otp/send
                      

                      

                        code
                        String
                        Yes
                        Verification code entered by user

Webhooks & DLR Events

              

                Configure a webhook URL to receive asynchronous delivery receipts (DLR) as messages transition through carriers:
              

              

                

                  Sample Webhook Payload

  "event": "otp.delivered",

  "status": "DELIVERED",
  "cost": "0.0500",
  "currency": "USD",
  "latency": "0.8s",
