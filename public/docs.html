Step 1

Authentication & Base URL

All OTP88 API requests require HTTPS and must include your API Key in the Authorization header formatted as a Bearer token:

Base URL 
https://api.otp88.com/v1
Authorization Header 
Authorization: Bearer otp_live_99882200aabbcc

POST

/v1/otp/send

Generates a cryptographically random verification code and delivers it using your chosen multi-channel strategy.

Request Body Parameters

Field Type Required Description
to String Yes Recipient phone in E.164 format (e.g. +60123456789)
channel_strategy String No waterfall (default), whatsapp, telegram, sms, voice
code_length Integer No Length of OTP (4 to 8 digits, default: 6)
expiry_seconds Integer No Validity window in seconds (default: 300)
POST

/v1/otp/verify

Validates the user-supplied code against the stored cryptographic token. 

curl -X POST https://api.otp88.com/v1/otp/verify \
  -H "Authorization: Bearer otp_live_99882200aabbcc" \
  -H "Content-Type: application/json" \
  -d '{
    "transaction_id": "tx_live_8820a9bc4",
    "code": "882049"
  }'
