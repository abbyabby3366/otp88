Cost control

Predictable spend, no surprise bills

Every send is authenticated with your API key, rate limited per key, and paid from a prepaid balance, so a runaway client or a bot loop cannot generate an unbounded bill.

Per-key rate limits

120 sends per minute per API key. Excess requests get HTTP 429 with a Retry-After header instead of being billed.

Prepaid balance

Sends stop when the balance runs out, and provider rejections are refunded automatically.

Full audit trail

Every OTP, refund and webhook attempt is logged in the console with the reference you pass in remark.
